# ORION AI · instaladores

**ORION AI** é um assistente de IA para Windows 10 e 11, em português do Brasil: conversa por voz, abre programas, dita texto em qualquer aplicativo (Ctrl+Alt+D), anota gastos e contas a pagar por voz e cria rotinas.

Este repositório guarda só os instaladores e as notas de versão usados pela atualização automática do app.
