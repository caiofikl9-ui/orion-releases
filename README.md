# ORION AI · instaladores

**ORION AI** é um assistente de IA para Windows 10 e 11, em português do Brasil: conversa por voz, abre programas, dita texto em qualquer aplicativo (Ctrl+Alt+D), anota gastos e contas a pagar por voz, cria rotinas, faz tarefas na internet com o agente da web e mostra um globo com dados ao vivo.

Este repositório guarda os instaladores e as notas de versão usados pela atualização automática do app.

## Baixar

O instalador mais recente fica em **[Releases → Latest](https://github.com/caiofikl9-ui/orion-releases/releases/latest)** (arquivo `ORION-Setup-x.y.z.exe`). Depois de instalado, o ORION se atualiza sozinho.

O instalador ainda não tem assinatura digital, então o Windows pode mostrar o aviso do SmartScreen. Clique em **Mais informações** e depois em **Executar assim mesmo**.
